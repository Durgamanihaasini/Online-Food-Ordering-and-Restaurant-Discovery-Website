
# Online Food Ordering and Restaurant Discovery Website

## Description
This project is a responsive food ordering and restaurant discovery website created using HTML and CSS.

## Features
- Responsive navigation bar using Flexbox.
- Food categories section.
- Six restaurant cards using CSS Grid.
- Hover effects on restaurant cards.
- Media queries for mobile, tablet and desktop screens.
- Container queries for responsive styling.

## Technologies Used
- HTML5
- CSS3
- Flexbox
- CSS Grid

## Testing
The website was tested on mobile, tablet and desktop screen sizes using Chrome Developer Tools.
